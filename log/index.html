Interpret the record carefully.

Timestamps show when RegOdds stored an alert, not when an underlying event first became public. Public APIs can be delayed or corrected. Absence from this log is not evidence that no event occurred. Past calls and simulated outcomes do not predict future results.

The public production record starts when the isolated publisher first synchronizes verified production output. An empty log means no production records have been published here yet; it does not imply that no private alerts were sent.
